# PROMPT.md — исходное ТЗ и постоянные просьбы

## Задача

Доделать бэкап + мониторинг прогу.
Всё сосредоточить на вебморде (основа кода — BackupChecker) и дебрендировать.
Назвать просто **BackupDotNet**.

## Ограничения

- .NET 4.8 без сторонних либ. Доступные в системе можно как DllImport/COM,
  а если либы внешние — декомпильнуть и в проект встроить.
  (Это важно: прога делается на случай отсутствия внешней сети.)
- Динамическая отказоустойчивость и логирование в `logs`:
  Trace без App.Config, листенеры — консоль и файлы `прога_дататайм.лог`
  в папке `logs`, **без бага дублирования листенеров**.

## Что уже сделано

- Дебрендинг, синяя палитра, логотип/фавикон/иконка.

- Документация: README, ROADMAP, CHANGELOG, `docs/*`.

## Постоянные просьбы владельца

Полный список — в [AGENTS.md](AGENTS.md). Главное:

1. **В конце каждой сессии открывать `ROADMAP.md` в панели просмотра OpenCode**
   (`tools.browser.preview({ path: "ROADMAP.md" })`) — чтобы владелец видел прогресс.
2. `bin\` — прод-инстанс, в git не попадает (`build.cmd` / `run.cmd`).
3. Брендинг прода — DPT (`config/branding.dpt.json`).
