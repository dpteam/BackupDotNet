# AGENTS.md — правила работы над BackupDotNet

Инструкции для ИИ-агента (и людей) в этом репозитории. Читать перед началом работы.

---

## 1. Постоянные просьбы владельца

### 1.1. Роадмап в браузере в конце каждой сессии ⭐

**В конце каждой сессии обязательно открывать `ROADMAP.md` в панели просмотра
OpenCode** (`tools.browser.preview({ path: "ROADMAP.md" })`), чтобы владелец
видел прогресс проекта.

Это не разовая просьба, а постоянное правило. Формулировка владельца:

> «Всегда показывай мне роадмап в браузере опенкода здесь же так же,
> с каждым концом сессии, чтобы я наблюдал за прогрессом.»

Порядок действий в конце сессии:

1. Обновить статусы в `ROADMAP.md`, если что-то сделано (🟢 / 🟡 / ⚪).
2. Вызвать `tools.browser.preview({ path: "ROADMAP.md" })`.
3. Коротко сказать в ответе, что изменилось и на каком этапе сейчас проект.

Если сессия была короткой и роадмап не менялся — всё равно открыть его.

**Резервный путь.** Если панель просмотра OpenCode недоступна
(`browser.disconnected`, namespace `browser` отвалился), собрать HTML и открыть
в системном браузере:

```powershell
powershell -ExecutionPolicy Bypass -File tools\show-roadmap.ps1
```

Скрипт конвертирует `ROADMAP.md` в `artifacts\roadmap.html` (стили встроены,
палитра как у веб-интерфейса) и открывает файл. В этом случае сообщить
владельцу, что использован резервный путь.

### 1.2. Прод-инстанс живёт в `bin\`

`bin\` — рабочий экземпляр: сборка, рабочие конфиги, история, журналы.
Каталог целиком в `.gitignore`: ни бинарники, ни конфиги, ни данные
в репозиторий не попадают. Собирается и обновляется через `build.cmd`
(`tools\build-prod.ps1`), запускается через `run.cmd`.

### 1.3. Брендинг прода — DPT

`config/branding.dpt.json` → `bin\config\branding.json` при сборке.
Название `DPT.Backup`, службы `DPTBackupService` / `DPTBackupRemote`.
Исходный продукт в коде называется `BackupDotNet` — брендинг меняется одним
файлом, без пересборки.

## 2. Технические ограничения (не нарушать)

1. **.NET Framework 4.8, ноль сторонних NuGet-пакетов.**
   Из внешнего допустимо только то, что уже есть в Windows:
   WMI (`System.Management`), `System.DirectoryServices`,
   Windows PowerShell 5.1 (`System.Management.Automation` из GAC).
2. **Программа должна работать без интернета.** Любая функция, требующая
   внешней сети, — только по явной настройке.
3. **Если нужна библиотека — декомпилировать и встроить исходники в проект.**
   Нельзя добавлять `<PackageReference>`.
4. **Собственные реализации уже есть и их надо переиспользовать:**
   JSON (`Json.cs`), HTTP-сервер (`WebHost`), ZIP (`ZipCollector`),
   Zabbix-протокол (`ZabbixSender`), генерация графики (`tools/generate-assets.ps1`).

## 3. Журналирование (жёсткое требование)

- Всё через `Log` (`src/BackupDotNet.Core/Log.cs`), который обёрнут вокруг
  `System.Diagnostics.Trace`. **Без App.Config** — листенеры подключаются в коде.
- `Log.Init` **идемпотентен**: повторный вызов не должен добавлять листенеры.
  Классический баг «каждая строка пишется N раз» уже исправлен — не возвращать.
- Формат строки — чистый, без префикса `Источник EventType: id :`.
  Для этого есть `PlainTraceListener` — не заменять на `TextWriterTraceListener`.
- Файл: `<dataDir>\logs\<Продукт>_<дата>_<время>.log`, UTF-8 без BOM.
- Ротация по размеру, автоочистка по возрасту, просмотр из веб-интерфейса.
- `Log` **никогда не бросает исключений** наружу.

## 4. Стиль кода

- Отступы — **табы**, ширина 4. Скобки — Allman (на новой строке).
- File-scoped namespaces: `namespace BackupDotNet.Core;`
- Приватные поля — `_camelCase`, публичные — `PascalCase`.
- Комментарии и сообщения — **русский**, идентификаторы — английский.
- Коллектор никогда не бросает наружу: любая проблема → `CollectResult`
  с `Reachable = false` и текстом ошибки.
- В HTML все пользовательские данные проходят через `esc()`.

Подробнее — `docs/DEVELOPMENT.md`.

## 5. Что где лежит

```
src/BackupDotNet.Core/    доменная логика (коллекторы, планировщик, хранилище)
src/BackupDotNet.Web/     HTTP, REST API, авторизация, роли
src/BackupDotNet.Deploy/  WinRM-развёртывание
src/BackupDotNet.Manage/  очередь операций (submit → approve → execute)
src/BackupDotNet.App/     точка входа, службы, CLI
public/                   веб-интерфейс без сборки (HTML/CSS/JS)
config/                   шаблоны + branding.dpt.json
tools/                    сборка, упаковка, генерация логотипа
bin/                      прод-инстанс (в .gitignore)
reference/                сторонние исходники для справки (не в сборке)
```
